## GitHub Pages setup

1. Sign in to GitHub as **muhammadahmed12371-bot**.
2. Create a new **Public** repository named **mohamed-el-naggar-card**.
3. Upload `index.html` to the repository's root (top level).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main**, folder **/(root)**, then click **Save**.
7. Wait a minute or two for GitHub Pages to publish the site.
